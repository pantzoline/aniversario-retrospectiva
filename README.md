# 🎂 A Jornada dos 21 Anos da Manu

Este é um projeto interativo web desenvolvido como um presente especial de aniversário de 21 anos para a Manu. É uma experiência rica e imersiva no estilo "Board Game / Spotify Wrapped" com trilha sonora, curiosidades, quiz e muitas emoções!

## 🔗 Repositório Oficial
Este código-fonte está salvo e versionado permanentemente no repositório do GitHub:
**[https://github.com/pantzoline/aniversario-retrospectiva.git](https://github.com/pantzoline/aniversario-retrospectiva.git)**

## 🚀 Como Rodar Localmente

1. Instale as dependências do projeto:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Acesse a aplicação no seu navegador padrão:
   Abra [http://localhost:3001](http://localhost:3001) (ou a porta listada no console).

## ✨ Tecnologias Utilizadas
- **Next.js 16 (App Router)** & React
- **Framer Motion** (para as animações fluidas)
- **Tailwind CSS** (Estilização Liquid Glass & Aura)
- Canvas Confetti
